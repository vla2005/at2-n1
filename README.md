# n2-at1

## Como iniciar o projeto

Instale as dependências:

```bash
npm install
```

Inicie o Expo:

```bash
npx expo start
```

Depois, escaneie o QR Code com o Expo Go no celular ou use uma das opções exibidas no terminal.

Também é possível iniciar diretamente por plataforma:

```bash
npm run android
npm run ios
npm run web
```
